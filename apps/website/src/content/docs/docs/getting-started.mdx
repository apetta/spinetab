## Connect your existing API

The setup guides let you switch between polling, SSE, WebSocket and fetch streams
without rewriting the component. For GraphQL, Socket.IO or an existing data
library, [choose your integration](/docs/choose-integration/): it shows which
sources fit each library and where to connect them in your framework.

Keep your library's hooks and providers when using an integration. You do not
need to add Spinetab's value hooks as well.

## Before you deploy

- Set up [authentication and user scopes](/docs/concepts/credentials/) if the feed contains user-specific data.
- Choose how the app [recovers missed events](/docs/concepts/continuity/). Reconnecting alone cannot recover data the server did not replay.
- Check [deployment requirements](/docs/deployment/) and [compatibility](/docs/compatibility/).

Custom decoders, protocol handlers and runtime settings belong in a
[custom worker](/docs/your-worker/). You can add one later without changing how
your components subscribe.
