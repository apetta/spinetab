## Give your agent the docs

- [llms.txt](/llms.txt) — the starting point for setup, integrations and API guidance.
- [recipe-index.md](/recipe-index.md) — complete examples by framework, data library and transport.

Every docs page has **Copy Markdown** and **View Markdown** actions for sharing
just the context you need.

The Markdown is generated from these docs and updates with every release.
